# Icones do frontend

Os icones Flaticon foram removidos.

A versao actual usa icones SVG locais, desenhados em linha arredondada para ficar alinhada com a referencia pedida:

https://www.magnific.com/br/autor/magnific/icones/basic-rounded-lineal_4

Segundo a propria pagina de icones da Magnific, os formatos gratuitos podem exigir atribuicao. Antes de substituir estes SVGs locais por ficheiros descarregados directamente da Magnific, confirmar a licenca de cada asset final e guardar os ficheiros definitivos em:

```text
frontend/public/assets/icons/
```
